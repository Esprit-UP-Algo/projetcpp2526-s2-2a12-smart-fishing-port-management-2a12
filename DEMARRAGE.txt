🔨 COMPILATION (3 méthodes)

MÉTHODE 1: Qt Creator GUI (Recommandée - Plus facile)
─────────────────────────────────────────────────────
1. Ouvrir Qt Creator
2. File → Open File or Project → VisionSightPoissons.pro
3. Qt Creator configure automatiquement
4. Build → Build Project (ou Ctrl + B)
5. Build → Run (ou Ctrl + R)

MÉTHODE 2: Script Windows (Facile - Automatisé)
────────────────────────────────────────────────
1. Ouvrir PowerShell ou CMD
2. Naviguer: cd "c:\...\interface arnoub"
3. Exécuter: .\build.bat
4. Le script compile et lance automatiquement

MÉTHODE 3: Ligne de commande manuelle (Avancé)
──────────────────────────────────────────────
1. qmake VisionSightPoissons.pro -spec win32-msvc
2. nmake (ou mingw32-make)
3. release\VisionSightPoissons.exe


❓ DÉPANNAGE RAPIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problème: "qmake: command not found"
Solution: Ajouter Qt bin au PATH:
          C:\Qt\6.7\msvc2022_64\bin

Problème: Erreur de compilation
Solution: Build → Clean All, puis relancer

Problème: La fenêtre démarre mais rien n'apparaît
Solution: Vérifier le fichier applyTheme() dans mainwindow.cpp

Problème: Table vide
Solution: Cliquer "Ajouter" pour créer des lots de démonstration
